# DSA Quest

A gamified interactive DSA visualization and learning platform built with a Python Flask backend and a browser-based frontend.

## Initial Algorithms

- Bubble sort
- Insertion sort
- Selection sort
- Quick sort
- Linear search
- Binary search

## Features

- Step-by-step animated visualizations
- Custom input values and search targets
- Play, pause, previous, and next controls
- Python and Java implementation tabs for every algorithm
- Dashboard cards for XP, streaks, level, and progress
- Practice, quiz, and competition sections for the learning workflow

## Run Locally

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

Open `http://127.0.0.1:5000` in your browser.
